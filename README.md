# Logithèque

Page qui rassemble les outils numériques faits maison pour l'équipe de la médiathèque de Servon-sur-Vilaine : Pixo, Vidéixo, PawDF, Mixo, Battle Pic, Suivixo, Planning bénévoles et Mini-b.

**Site :** https://mediatheque-ssv.github.io/logitheque/

Tout tient dans `index.html` (icônes intégrées dans la page). Pour ajouter ou modifier un outil, il suffit de changer la liste `TOOLS` en bas du fichier.
